# FollowYou

Follow-spot control software by **Sceneproff**.

This repository holds the official FollowYou releases. Download the newest installer
under **Releases**. FollowYou checks here for updates by itself when the station is
online.

Without a licence FollowYou runs in DEMO mode. For a licence (USB key or licence file),
contact Sceneproff.
